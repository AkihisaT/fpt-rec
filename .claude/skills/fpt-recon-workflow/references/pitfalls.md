# FPT 再構成の注意点（003、018、036、32a の解析から）

数値はそのデータでの値です。新しいデータの基準値ではありません。

## 実験条件と位置

- **申告値を確かめる**：32a では Δr（申告 200 nm → データ 250 nm）と FZP Y の単位（申告 0.6 µm → 0.2 µm）が違っていました。
  Δr は瞳の半径（kc = 1/(2Δr)）から、ステージの単位はリングが円になる条件から確かめます。
- **ステージの丸め**：32a では、FZP X は整数パルス（2.5 µm/パルス）なのに、検出器の値は 1.25 µm 刻みのレンズ位置で計算されていました。
  約 44 % の画像が 1.25 µm（39.1 px）ずれていました（`d32a/prep_32a_reg.py` で補正）。原因の説明では「FZP X を丸めない」とは言いません
  （パルスのステージでは不可能）。「送った整数パルスから検出器の値を計算する、設計値をパルスにするときは四捨五入する」と提案します。
  この飛びの傾き（−0.994）から画素サイズ 32.1 ± 1.4 nm/px を確かめられました（名目 31.9）。
- **機械的なドリフト**：32a では、画像のずれがレンズ位置に比例していました（2×2 行列：col←X −1.59 %、col←Y +0.96 %、回転 +0.31°）。
  補正する前は、瞳がこれを大きな非点収差（焦点 1.5 / 9.6 mm）として吸収し、楕円状のぼけが出ました。`posaffine` が補正します。
- **物体と瞳のピントの縮退**：像のコントラストに対して、物体の 2 次位相と瞳の 2 次位相は区別できません（和だけが決まる）。
  視差は瞳からだけ生じます。物体のピントのずれ z は「瞳のピント z + 視差 λzk」と同じで、k に比例する視差は等方的な倍率と区別できません。
  「物体にピントが合っている」という条件で解を選びます（フォーカスループ）。
- **自動のピント合わせ**：EPRY と BLIS-FPM の物体には使えます（合成データで偏り −0.01 mm）。DIP の物体は振幅と位相が結びついているので
  常に 0 になり、判断に使えません。

## 較正

- WOTF の較正の地形は多峰的です。`fig1_calibration.png` で、瞳の円がリング 3 の砂時計形のスペクトルに合うか必ず確かめます。
  quick モードは動作確認用です。
- 過去の較正：003 は回転 90.04°、名目の 1.31 倍（0.2735 µrad/パルス）、瞳の中心のずれ k0 (0.37, −0.30) µm⁻¹、ピント 0.9 mm。
  018 は 1.15 倍。036 は 1.32 倍、twin −1。
- 32a（平行ビーム）では WOTF の較正が合いません（misfit ≈ 0.8）。試料なし画像の口径食（円板の縁、tanh の幅）を、
  x_c = A d + c0（A は 2×2）で当てはめました：A ≈ −0.84（等方的）、R_field 51.4 µm、リングごとの |k|/kc の中央値 0.49–1.64。
  リング 0–1 の比の画像には FZP 0 次光の弧の縞があります。

## 明視野と暗視野

- |k|/kc が 1 を少し超えるリング（036 のリング 2、1.31–1.37）は、部分コヒーレントな直接光の裾（中心で明視野の 2–5 %）と縁の縞が
  コントラストを支配し、コヒーレントなモデルでは合いませんでした（除外）。
- 暗視野のデータには、モデルで説明できない一様な背景が加わります（036：データの平均がモデルの約 10 倍（リング 2）、2.6 倍（リング 3））。
  暗視野の画像ごとの強度係数（DIP：`dark_gain: profile`、EPRY：最初の訪問で推定して固定）を使います。
- EPRY の強度係数を毎周推定し直すと、暗視野の画像で係数が 0 に落ちる固定点があります（最初の訪問で推定して固定する方式を実装済み）。
- 周期的な格子で FOV の 2 次位相を使うと、格子の端に偽の直接光が出ます。暗視野のモデルとデータは、窓で重み付けした平均で規格化します。
- BLIS-FPM の平面波モデルで、ゼロから始めると暗視野の画像で 0/0 になって失敗します。明視野の解から始めます（warm start）。
- 明視野＋暗視野で、検証用の画像の平均 misfit で反復を選ぶと、暗視野の画像（misfit > 1）が支配します。EPRY は非常に早い周を選び
  （32a 1000 画素 FOV で周 0、ぼけた像）、明視野の予測も悪くなります。明視野の検証画像だけで選ぶ方式は未検討です。
- 036、32a とも、暗視野を加えても、検証用に除いた暗視野の画像は予測できませんでした（misfit ≈ 1 以上）。
  036 ではスポークの限界が上がりました（BLIS-FPM 3.27 → 4.85 µm⁻¹、DIP 最適反復 3.39 → 3.90）。
  32a では FRC もスポークも上がりませんでした。ピントのずれを直す前は、明視野の限界より上の成分のコントラストが反転していました。
  直した後は反転しなくなりましたが、その帯域の成分（+0.05 / +0.03）はノイズ（0.09 / 0.08）と同程度でした。
  「暗視野で分解能が上がった」と言う前に、検証用の画像の予測、FRC、符号付きの MTF で確かめます。
- 32a の暗視野の画像で、DIP が学習したずれは ±5 px の上限に張り付きました（95 枚中 58–75 枚）。SNR < 1 の暗視野でノイズに合わせた結果で、
  位置の誤差ではありません。

## 部分コヒーレンス

- 036：試料なし画像の直接光は瞳の縁の外にゆっくり減衰しました（1.2 kc で 0.1、1.45 kc で 0.01、1.8 kc で 0.003）。
  角度分布 S = ガウスの芯（σ 0.02 kc）＋ハロー η（2 次元コーシー、ℓ 0.1 kc）。η 0.1 と 0.3 は区別できず 0.1 を採用。芯の幅は直接光だけでは決まりません。
  約 20 モードで、検証用の明視野の misfit は 7–20 % 下がりましたが、暗視野の予測と分解能は変わりませんでした。
- 32a：瞳の縁のぼけは等方的（H 1.79 µm、V 1.74 µm）で、角度広がりは NA の数 % 以下。部分コヒーレンスは不要と判断しました。

## 手法ごとの注意

- **DIP**：早期停止が必須です。検証用の画像（keep[::9]）のずれと係数は、物体と瞳を固定して別の MLP で合わせます。
  最小値から 1 % 以内の最も早い評価を選びます（`select_tol`）。全帯域の強度の MSE はノイズが支配するので停止の判断に使えません。
  最適反復はデータで大きく違います（003：20–40、018：120–190）。
- **EPRY**：単位の歩幅では 003 で収束しません（misfit ≈ 1.0）。適応的な歩幅（Zuo 2016）を既定にしています。
  明視野だけのデータでは瞳の更新がほとんど効きません（瞳の変化 < 1e-4 rad）。rPIE 型の瞳の自由度は過学習しました。
- **BLIS-FPM**：コストが 0.3–3.5 µm⁻¹ の帯域なので、分解能の上限はほぼ 3.5 µm⁻¹ です。018 の FOV モデルの全視野の解は、位相のパワーの
  約 72 % が 3.5 µm⁻¹ より上にあり、信頼できませんでした（物体の帯域制限 `d018/tools/blis_objband.py` で改善）。
  画像ごとの自由なコントラスト係数は、物体のコントラストと縮退するので使いません。
- **1024 画素の FOV モデル**：|k|/kc ≥ 0.9 の画像では、視野の端でモデルの直接光が瞳の外に出ます。口径食のマスクがないと、
  DIP の損失が約 5 倍になり、EPRY に縞が出ます。

## 分解能の評価

- シーメンススターの中心は、内側と外側で数画素ずれることがあります（32a：r < 85 px の中心が外側より約 5 px ずれていた）。
  中心を一つにすると、すべての手法に偽の上限（内側の円 36/(2π·85 px) ≈ 2.1 µm⁻¹）が出ます。内側と外側で別の中心を使います。
- スポークの SNR > 3 の値がスターの中心の円の内側（018 では約 5.0 µm⁻¹ より上）に入ったら、「チャートの限界に達した」と読みます。
- FRC：DIP の半分データは異なる seed で解きます。合成開口の限界より上の FRC（32a EPRY：4.5 µm⁻¹ で 0.8、パワー約 1e-5）は
  決定的な漏れで、分解能ではありません。
- 符号付きの MTF（スポークの 36 次の複素調和成分）で、コントラストの反転を見分けます。
